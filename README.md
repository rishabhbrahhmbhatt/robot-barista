# Robot Barista

A beginner Python project: a robot barista that takes a customer's name, coffee order and quantity, then calculates the total price.

## What I used
- `input()` to take user input
- `int()` and `str()` for type conversion
- String concatenation with `+`

## How to run
python robot_barista.py
